# Examples

- [`local_qlib_backtest/`](local_qlib_backtest/README.md): use the repository's immutable local
  Qlib data to train a model, generate signals, and run an A-share simulation backtest. It includes
  LightGBM, Qlib Ridge, and a custom model plug-in.

All examples are research-only. They do not submit orders or publish production artifacts.
