Economic interpretation

  • The score has diagnostic separation, but the realized constrained portfolio does not beat CSI300.
  • Using the same annualized arithmetic convention, gross strategy return is approximately 11.48% and net strategy return approximately 8.81% versus a 15.49% benchmark.
  • The difference between no-cost and after-cost excess return is about 2.67 percentage points per year: turnover and execution policy materially matter.
  • A high Long-Avg diagnostic is therefore not evidence that the production-like portfolio is economically viable.

Why REJECT is correct

  • The mean RankIC hurdle is cleared, so the data is not devoid of signal.
  • The stability channel is far below the 0.50 promotion threshold.
  • Benchmark-relative portfolio economics are negative after costs.
  • The right response is better evidence and more robust alpha, not lowering the gate.

7 · Data-quality watchlist

Observed warnings

  • load calendar error: freq=day, future=True; return current calendar
  • RuntimeWarning: Mean of empty slice appeared repeatedly during backtest.

Required follow-up

  • Separate genuine suspension/untradable sessions from provider-side missing open prices.
  • Report OHLCV NaN ratio by date and instrument, valid-stock count per cross-section, label coverage and benchmark completeness.
  • Do not blindly fill missing open with close; that can create false executions.
  • Repair/verify future-calendar configuration before using the same path for forward-looking orchestration.

8 · Next stock-research program

  1. Data QA first: resolve open-price and empty-cross-section warnings.
  2. Model baseline: hold alpha158_market_v1 fixed and compare Ridge / LightGBM / XGBoost.
  3. Data ablation: Market → Daily → PIT → multifactor_core_v1.
  4. Walk-forward: replace single fixed split with rolling OOS and inspect fold RankIC, ICIR, worst fold and positive-fold ratio.
  5. Label horizon: compare 1D / 5D / 10D / 20D outcomes before assuming daily prediction is optimal.
  6. Own factors: pre-register Value, Profitability/Quality, Momentum, LowVol, Liquidity and Fundamental Momentum hypotheses.
  7. Incremental tests: compare Alpha158 versus Alpha158 + candidate factor; avoid keeping factors that only duplicate existing features.
  8. Portfolio layer last: tune TopK / n_drop / hold period only after stable alpha exists, then stress costs at 1× / 1.5× / 2×.
  9. Sealed holdout: use the final holdout once, only after feature/model/portfolio decisions are frozen.
